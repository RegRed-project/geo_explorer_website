Geographic Entities Explorer

    This tool lets you explore the geographic entities in the RegRed database.

  • Choose a table, then search it.
  • The wide box above the table looks for a word in any column and also matches part of a value.
  • The boxes above each column filter that column: by default they must match the whole value (case is ignored); tick Allow partial matches to match part of it instead.
  • All filled-in boxes must match.
  • Inside any box, combine words with upper-case OR (either) and AND (both), e.g. Prague OR Paysandú OR Valdivia; AND is applied before OR.
  • Press Enter or Query to run the search, and Reset to clear all boxes.
  • Press Show on a row to display the map.
  • Copy visible rows copies the table as tab-separated text, ready to paste into a spreadsheet.
